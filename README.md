# MNIST Digit Classification - Deep Learning

**Ονοματεπώνυμο:** Χριστίνα Κασκαμπά  
**ΑΕΜ:** 4836  
**Μάθημα:** Τεχνητή Νοημοσύνη

## Στόχος της Εργασίας
Στόχος αυτής της εργασίας είναι η κατασκευή, εκπαίδευση και βελτιστοποίηση Βαθιών Νευρωνικών Δικτύων (Deep Neural Networks) για την ταξινόμηση χειρόγραφων ψηφίων (από το 0 έως το 9) χρησιμοποιώντας το γνωστό σύνολο δεδομένων MNIST (60.000 εικόνες εκπαίδευσης). Η υλοποίηση πραγματοποιήθηκε σε γλώσσα Python με τη χρήση της βιβλιοθήκης TensorFlow/Keras.

## Υλοποίηση και Βελτιώσεις (Workflow)
Η αρχική αρχιτεκτονική του μοντέλου τροποποιήθηκε σε διάφορα στάδια για να επιτευχθεί η μέγιστη δυνατή ακρίβεια. Τα βασικά βήματα της υλοποίησης ήταν τα εξής:

### 1. Προεπεξεργασία Δεδομένων (Data Preprocessing)
Τα δεδομένα εισόδου (ασπρόμαυρες εικόνες 28x28) μετατράπηκαν σε διανύσματα (784 features). Η σημαντικότερη βελτίωση που εφαρμόστηκε σε αυτό το στάδιο ήταν η **Κανονικοποίηση (Normalization)** των τιμών των pixel στο διάστημα [0, 1] διαιρώντας με το 255.0. Αυτή η προσέγγιση βοήθησε τον αλγόριθμο βελτιστοποίησης (SGD) να συγκλίνει πολύ ταχύτερα. Οι ετικέτες (targets) μετατράπηκαν σε μορφή One-Hot Encoding.

### 2. Hyper-parameter Tuning
Το αρχικό δίκτυο (Base Model) βελτιώθηκε σημαντικά δοκιμάζοντας διαφορετικές υπερπαραμέτρους:
* **Αρχιτεκτονική:** Προστέθηκε ένα επιπλέον κρυφό επίπεδο (από 2 σε 3), αυξάνοντας τη χωρητικότητα του δικτύου ώστε να μάθει πιο πολύπλοκα χαρακτηριστικά (χρησιμοποιήθηκαν 512, 256 και 128 νευρώνες αντίστοιχα).
* **Συνάρτηση Ενεργοποίησης:** Η συνάρτηση `tanh` αντικαταστάθηκε από την **`relu`** (Rectified Linear Unit), εξαλείφοντας το πρόβλημα της εξαφάνισης της κλίσης (vanishing gradient) στα βαθιά επίπεδα.
* **Εκπαίδευση:** Το Learning Rate του αλγορίθμου SGD αυξήθηκε στο `0.01` και οι εποχές (epochs) αυξήθηκαν στις `20`, δίνοντας στο μοντέλο τον απαραίτητο χρόνο να εκπαιδευτεί σωστά.

### 3. Ανάλυση Λαθών (Validation & Error Analysis)
Προστέθηκε ειδικό τμήμα κώδικα που εντοπίζει και οπτικοποιεί τις λανθασμένες προβλέψεις (misclassifications) του μοντέλου πάνω στο Test Set. Η εφαρμογή τυπώνει ένα λάθος για κάθε κλάση (0-9), εμφανίζοντας την εικόνα, την πραγματική ετικέτα και την εσφαλμένη πρόβλεψη, επιτρέποντας την ποιοτική αξιολόγηση των αδυναμιών του δικτύου.

## Αποτελέσματα
Μετά την εφαρμογή της κανονικοποίησης και το hyper-parameter tuning, το τελικό μοντέλο παρουσίασε πολύ πιο σταθερή καμπύλη εκπαίδευσης και πέτυχε συνολική ακρίβεια (Accuracy) **97.97%** στο Test Set.
